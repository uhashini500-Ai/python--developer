# ShadowFox Python Internship

## About This Project

This repository contains five Python programs completed as part of my ShadowFox Python Developer Internship.

The programs demonstrate fundamental Python concepts, including variables, numbers, lists, dictionaries, and classes and objects.

## Programs Included

### 1. Variables

File Name: variables.py

Description:

This program demonstrates the use of variables and data types in Python. It also explains Python reserved keywords and performs a simple interest calculation.

Concepts Covered:
- Variable declaration and assignment
- Data types
- Python reserved keywords
- Arithmetic operations
- Simple interest calculation

### 2. Numbers

File Name: numbers.py

Description:

This program performs mathematical calculations using Python. It demonstrates number formatting, calculating the area of a circular pond, finding the quantity of water, and calculating speed.

Concepts Covered:
- Number formatting
- Mathematical operations
- Exponentiation
- Type conversion
- Area calculation
- Speed calculation

### 3. Lists

File Name: lists.py

Description:

This program demonstrates Python list operations and expense tracking. It creates lists, calculates the length of names, compares expenses, and identifies the category with the largest spending difference.

Concepts Covered:
- Lists and tuples
- List comprehension
- Dictionaries for expense tracking
- List operations
- Loops and conditional statements
- Calculating total expenses
- Comparing expenses

### 4. Dictionaries

File Name: dictionaries.py

Description:

This program demonstrates how dictionaries store information using key-value pairs. Dictionaries can be used to organize, access, update, and compare data efficiently.

Concepts Covered:
- Creating dictionaries
- Key-value pairs
- Accessing dictionary values
- Adding and updating entries
- Dictionary methods
- Iterating through dictionaries

### 5. Classes and Objects

File Name: classes_objects.py

Description:

This program demonstrates Object-Oriented Programming (OOP) in Python using an Avenger class. It creates superhero objects and displays their details, including name, age, gender, superpower, weapon, and leadership status.

Concepts Covered:
- Classes and objects
- Constructor method __init__()
- Object attributes
- Instance methods
- The self parameter
- Creating multiple objects
- Conditional statements

## Technologies Used

- Programming Language: Python
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub

## How to Run the Programs

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the required program using the following command:

python variables.py
To run another program, replace variables.py with the required filename.

For example:

python numbers.py
python lists.py
python dictionaries.py
python classes_objects.py
